# Coloph Works

**An opinionated, agent-native foundation for building better software.**

Coloph Works brings together focused packages for starting new projects and improving existing ones. Each package is designed to be easy to adopt, useful on its own, and effective for both developers and coding agents.

- **Agent-native** — Clear interfaces, predictable behavior, and workflows that agents can use reliably.
- **Opinionated** — Strong defaults that remove decisions and keep projects consistent.
- **Easy to adopt** — Add one package at a time, without rebuilding your project around a framework.
- **Built for real projects** — Practical infrastructure for development, collaboration, and deployment.

## Packages

- [coloph-env](https://github.com/golergka/coloph-env) — Strict startup environment configuration for Python.
- [coloph-install-skills](https://github.com/golergka/coloph-install-skills) — Install agent skills bundled with local development dependencies.
- [coloph-migrations](https://github.com/golergka/coloph-migrations) — Agent-friendly PostgreSQL migration CLI.
- [coloph-sync](https://github.com/golergka/coloph-sync) — Commit checks, worktree integration, and deployment coordination for any Git project.
