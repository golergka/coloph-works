# Coloph Works

Open-source packages extracted from Coloph projects for reuse across different kinds of work.

## Packages

- [coloph-env](https://github.com/golergka/coloph-env) — Strict startup environment configuration for Python.
- [coloph-install-skills](https://github.com/golergka/coloph-install-skills) — Install agent skills bundled with local development dependencies.
- [coloph-migrations](https://github.com/golergka/coloph-migrations) — Agent-friendly PostgreSQL migration CLI extracted from Coloph.
- [coloph-sync](https://github.com/golergka/coloph-sync) — Commit checks, worktree integration, and deployment coordination for any Git project.
